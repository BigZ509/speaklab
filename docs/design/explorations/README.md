# SpeakLab 2.0 Phase 5 visual explorations

These are **concept renders**, not application screenshots and not production
assets. They retain the same Week 1 functionality and use illustrative,
clearly non-live transcript/filler content.

## Render files

- `speaklab-direction-comparison-board.png` — six concepts in the intended
  comparison order: Editorial recording/results; Instrument recording/results;
  Expressive Minimalism recording/results.
- `editorial-recording.png`, `editorial-results.png`,
  `instrument-recording.png`, `instrument-results.png`,
  `minimalism-recording.png`, and `minimalism-results.png` — individual
  rendered exploration exports retained alongside the board.

## Direction A — Editorial Practice Studio

Recording uses an ivory page, high-contrast serif display heading, a soft
prompt card, and cobalt microphone focal point. Results use a transcript-led
reading card and compact factual filler count. Type: editorial display plus
neutral sans labels; color: ivory, ink, cobalt. Motion: none beyond a subtle
active-control scale. References: Hinge voice screens, Insight Timer reading,
Perplexity transcript. Benefit: calm and legible; trade-off: its refinement
depends on excellent typography rather than ornament.

## Direction B — Interactive Recording Instrument

Recording turns time into the visual focal point: oversized timer, concentric
control rings, and a compact status. Results preserve the object-like metric
and place transcript beneath it. Type: large tabular timer plus restrained
sans; color: pale graphite, ivory, cobalt. Motion: ring breathes only while
recording, never claims audio reactivity. References: WHOOP breathing,
Givingli voice note, Once tape recorder. Benefit: memorable recording ritual;
trade-off: must be carefully tuned so the timer does not overpower the prompt.

## Direction C — Expressive Minimalism

Recording uses a cobalt field as the task moment, an off-white prompt strip,
black stop object, and large timer. Results return to an ivory reading surface
with one cobalt vertical progress rail. Type: assertive display + compact
utility labels; color: cobalt as a full compositional field only during active
recording. Motion: state transition from ivory to cobalt, respecting reduced
motion. References: Claude voice input, Arc Search, Noom. Benefit: strongest
recognition at a glance; trade-off: highest contrast and accessibility review
burden.

## Comparative judgment

| Direction | Distinctiveness | Readability | Control clarity | React Native fit | Main risk |
| --- | --- | --- | --- | --- | --- |
| Editorial | High | Highest | High | High | can feel quiet without typographic polish |
| Instrument | Highest during recording | High | Highest | Medium | visual weight can eclipse the prompt |
| Minimalism | High | High in results | High | Medium | active cobalt field needs careful contrast testing |

### Recommendation

**Interactive Recording Instrument** is the strongest long-term identity:
its timer-plus-control geometry makes repeated speaking practice recognizable
without adding data or features. It combines WHOOP’s time focal point,
Givingli’s layered microphone, and Once’s composed recorder, while retaining
Perplexity-style transcript readability for results. The component system can
extend to future exercises without becoming a dashboard.
